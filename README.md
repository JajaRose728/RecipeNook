# RecipeNook

RecipeNook is a Flutter app that allows users to create, view, and manage their personal recipes. It supports both public and user-specific recipe streams.

## Features

- Add, edit, and delete recipes
- View public recipes and your own recipes separately
- Clean and responsive Flutter UI
- Firebase/Firestore integration for real-time updates
